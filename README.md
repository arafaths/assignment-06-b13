# DigiTools - SaaS Landing Page

DigiTools is a modern, high-performance landing page designed for a digital product marketplace or SaaS platform. It features a clean UI, engaging animations, and a fully responsive design tailored for digital workflows.

![Project Preview](https://via.placeholder.com/800x400?text=DigiTools+Landing+Page+Preview) ## 🚀 Key Features

* **Hero Section:** High-converting headline with clear Call-to-Action (CTA) buttons.
* **Dynamic Stats:** Interactive counters showing 50K+ Active Users and 200+ Premium Tools.
* **Product Showcase:** Grid layout featuring specialized tools like AI Writing Pro, Design Templates, and Automation Toolkits.
* **Step-by-Step Guide:** Clean onboarding flow (Create Account -> Choose Products -> Start Creating).
* **Tiered Pricing:** Fully responsive pricing tables (Starter, Pro, Enterprise) with feature lists.
* **Modern UI/UX:** Built with a purple-centric color palette, sleek shadows, and professional typography.

## 🛠️ Tech Stack

* **Frontend:** React.js 
* **Styling:** Tailwind CSS / Daisyui
* **Icons:** Lucide React 
* **Deployment:** Netlify

## 🏁 Getting Started

Follow these steps to run the project locally:

1.  **Clone the repository:**
    ```bash
    git clone [https://github.com/arafaths/assignment-06-b13](https://github.com/arafaths/assignment-06-b13)
    ```

2.  **Navigate to the project directory:**
    ```bash
    cd digitools-landing-page
    ```

3.  **Install dependencies:**
    ```bash
    npm install
    ```

4.  **Run the development server:**
    ```bash
    npm run dev
    ```
